# B1 Syrer App

تطبيق أندرويد مجاني لتحضير امتحان B1 الألماني للسوريين والعرب في ألمانيا.

Free Android app for preparing for the German B1 exam, targeting Syrians and Arabs in Germany.

## Features

- B1 Exam preparation (Reading, Listening, Writing, Speaking)
- Leben in Deutschland (460+ questions)
- Grammar rules and vocabulary (350+ words)
- Writing templates
- Level test
- Study planner & achievements
- Fully bilingual (German/Arabic) with RTL support
- Offline capable

## Tech Stack

- React Native with Expo
- TypeScript
- React Navigation v7
- AsyncStorage for offline data

## Getting Started

```bash
npm install
npm start
```
